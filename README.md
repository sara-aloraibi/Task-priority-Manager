# Task Priority Manager
A console-based Java application designed for tracking student tasks, managing due dates, and filtering tasks based on execution status and priorities.
## Features
- **Task Tracking:** Manage task titles, priority levels (HIGH, MEDIUM, LOW), and due dates.
- **Status Filtering:** View full task lists or narrow down to pending action items.
- **Date Handling:** Utilizes Java `LocalDate` for real-time schedule management.
- **Input Validation:** Safe handling for date parsing and priority types.
## Tech Stack
- **Language:** Java 17+
- **IDE:** IntelliJ IDEA
- **Concepts:** Object-Oriented Programming (OOP), Java Enums, `java.time` API, Collections
## How to Run
1. Clone or download the repository.
2. Open the project in **IntelliJ IDEA**.
3. Run `Main.java` from the `src` folder.
